1. Analyze each note's title and content
2. Either assign it to an existing folder OR suggest a new folder
3. Group related notes together
4. Create meaningful folder names that describe the category

Return your response as JSON with this exact structure:
{{
  "new_folders": [
    {{"name": "Folder Name", "description": "Brief description", "note_ids": ["note-id-1", "note-id-2"]}}
  ],
  "existing_assignments": [
    {{"folder_id": "existing-folder-id", "note_ids": ["note-id-3", "note-id-4"]}}
  ]
}}
